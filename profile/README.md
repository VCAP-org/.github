# VCAP

**Prove a photo or video is untouched since capture.**

Generated and edited media now look exactly like real ones. VCAP seals each photo
or video the moment it is taken — with a signature from the device's secure
hardware where the device attests it, a browser session key where it does not —
plus an invisible watermark. Any later change, by AI or by hand, breaks the seal.

Verification runs entirely in the browser: no account, no trust in our servers.

## Public repositories

- [**vcap-spec**](https://github.com/VCAP-org/vcap-spec) — normative specification
  of the proof format, JSON Schema and conformance test vectors.
- [**vcap-verifier**](https://github.com/VCAP-org/vcap-verifier) — the public
  client-side verifier and the shared verification core.
